# data/reports/

This is the published archive. Every `<report_date>.json` file here is built into the public site at ari3lla.com.

**Status (2026-09-22):** empty. The archive restarts here with the first report that meets the evidence standard below.

## What a report needs before it can go here

- **A `report_date` on or before the day it's committed.** No report may describe a week that hasn't happened yet.
- **An article URL for every claim.** Each signal must link to the specific, fetched page it rests on. A bare outlet domain (`vogue.com`) is not evidence.
- **No invented sources.** If evidence can't be found, the report says "not found."
